# SQLite 存储与备份

服务默认把玩家、房间、战绩和俱乐部保存在 `data/state.sqlite`。第一次启动时，如果数据库尚未初始化且存在 `data/state.json`，服务会在一个事务中自动导入旧存档。导入成功后，旧 JSON 会保留作为迁移前备份，后续数据只写入 SQLite。

数据库使用 WAL 日志和 `synchronous=FULL`。一次游戏状态保存会在一个事务内更新所有相关表，写入失败时保留上一个完整快照。

运行中的服务可以直接执行在线备份：

```sh
npm run backup
```

备份默认写到 `data/backups/state-时间.sqlite`，完成前会执行 SQLite 完整性检查。也可以指定目标文件：

```sh
node tools/backup-state.js /path/to/state-backup.sqlite
```

环境变量：

- `QJQP_DB`：SQLite 数据库路径，默认 `data/state.sqlite`。
- `QJQP_STATE`：仅用于首次迁移的旧 JSON 路径，默认 `data/state.json`。

部署环境需要 Node.js 22 或更高版本。不要在服务运行时直接复制 `state.sqlite`，因为最新数据可能还在 WAL 文件中；使用备份命令生成一致性副本。

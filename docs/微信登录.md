# 微信登录配置

当前 Android 客户端已经包含微信登录原生代码。重新签名后，必须在微信开放平台登记新签名，并使用自己移动应用的 AppID。

微信开放平台移动应用填写：

- Android 包名：`com.haoke.gandengyan`
- Android 应用签名：`5a5996d5a09e4e862feaed2b1fe779f3`
- 签名算法：APK 签名证书的 MD5，小写且不带冒号

开放平台审核通过并取得 AppID、AppSecret 后，在项目根目录 `.dev.vars` 增加：

```dotenv
QJQP_WECHAT_APPID=wx替换为开放平台AppID
QJQP_WECHAT_APPSECRET=替换为开放平台AppSecret
```

`AppSecret` 只由服务端读取，不会写入 APK。构建脚本只把 `QJQP_WECHAT_APPID` 写入 AndroidManifest。运行：

```bash
npm run apk:install
```

命令会生成带时间戳的 APK、用 `~/.android-qjqp.keystore` 中的 `gandengyan` 私钥别名签名，并安装到所有在线 ADB 设备。这个签名库必须长期保留；更换签名后需要重新修改微信开放平台登记的应用签名。

服务端收到客户端的一次性授权码后，会通过微信接口换取用户身份，并以 `openid`/`unionid` 复用已有玩家账号。微信 access token 和 AppSecret 都不会返回客户端或写入存档。

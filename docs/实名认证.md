# 实名认证

客户端通过协议 101 查询实名状态，通过协议 102 提交姓名和身份证号。服务端只允许登录用户操作，并执行以下检查：

- 姓名为 2 至 30 位中文字符，可包含一个中文间隔号；
- 身份证为 18 位中国大陆居民身份证；
- 检查地区码、实际出生日期、顺序码和 MOD 11-2 校验位；
- 每个账号只能认证一次，同一身份证只能绑定一个账号。

为减少敏感数据风险，SQLite 不保存完整姓名和身份证号。存档中只有姓名首字、脱敏身份证号、认证时间，以及使用 `QJQP_ID_HASH_KEY` 生成的 HMAC-SHA256 摘要。这个密钥位于 `.dev.vars`，不要提交到 Git，也不要随意更换；丢失或更换后，系统无法继续识别旧身份证的重复绑定。

当前认证级别为 `format`：它能确认身份证格式、日期和校验位真实有效，但不能证明姓名与身份证属于同一人。正式上线前应接入具备资质的权威实名核验服务，并在服务端核验通过后再写入认证状态。

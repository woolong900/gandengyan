# 大厅右上角消息

右上角消息列表显示俱乐部邀请和运营通知。俱乐部管理员可在俱乐部邀请页面搜索玩家并单独邀请，也可从可邀请玩家列表选择最多 100 位玩家批量邀请。邀请写入服务端存档；被邀请玩家可同意或拒绝。同意后加入俱乐部，邀请从待办列表移除。

运营通知由服务器管理员在项目目录执行以下命令发布，命令通过 SSH 访问服务器本机的受保护接口，不会把密钥发往公网：

```bash
node tools/operator-message.js send --title '维护通知' --content '今晚 22:00 维护，请提前结束牌局。'
node tools/operator-message.js send --title '个人通知' --content '请联系管理员。' --uid 100001
node tools/operator-message.js send --title '较长通知' --content-file /绝对路径/通知正文.txt --days 7
node tools/operator-message.js list
node tools/operator-message.js delete --id 1000000000
```

不填 `--uid` 时通知发给全部玩家，也会在有效期内显示给新注册玩家。默认有效期 30 天，可用 `--days` 设置 1 至 365 天。正文最长 300 字、标题最长 32 字。玩家点击“查看”后通知标记为已读，消息仍留在列表里，右上角红点只计未读通知和待处理邀请。撤回通知会让它从收件人的列表消失。

服务器首次启用此功能时，需要由管理员生成 `/var/lib/qjqp/operator.key`，设置权限为 `0600` 并由服务账号 `qjqp` 持有。这个密钥不应提交到 Git 或放入客户端包。后台 API `/operator/messages` 要求 `Authorization: Bearer <密钥>`，且只由服务器本机的管理脚本调用。

# 潜江干瞪眼管理后台

线上入口：[https://game.auxvv.com/admin](https://game.auxvv.com/admin)。后台使用独立管理员密码；密码仅以加盐 scrypt 哈希保存在服务器 /var/lib/qjqp/admin-password.json，不放进 Git、安装包或浏览器存储。登录会话为 8 小时，保存在服务器内存中；服务重启后需要重新登录。浏览器仅接收 HttpOnly、SameSite=Strict、Secure 会话 Cookie，修改操作另需 CSRF 令牌。密码错误会限速。可在「备份与系统」页面修改密码，修改后全部会话立即失效。

后台目前有九个入口：

| 入口 | 能做什么 |
| --- | --- |
| 数据面板 | 玩家总数、在线人数、活跃房间、俱乐部、房卡余额、归档牌局及最近七天趋势 |
| 玩家管理 | 按 ID/昵称搜索，查看房卡、房间、俱乐部与脱敏实名状态；调整房卡、停用/恢复账号 |
| 房间管理 | 查看当前房间状态、座位、机器人、托管和配置；管理员可解散异常房间 |
| 牌局管理 | 按房号、战绩 ID 或玩家 ID 查归档战绩、每局积分与回放编号 |
| 俱乐部管理 | 查看部长、成员、玩法、房间；设置俱乐部公告及关闭状态 |
| 通知管理 | 向全部玩家或指定玩家发布文字通知，设有效期、撤回通知 |
| 大厅公告 | 设置大厅滚动公告、客服微信与 QQ；在线玩家立即刷新 |
| 操作日志 | 审计登录、房卡调整、房间解散、账号状态、通知和设置变更 |
| 备份与系统 | 生成 SQLite 在线备份、查看存档信息、修改管理员密码 |

房卡调整要求填写原因，不能扣成负数。停用仍在房间里的玩家会被拒绝，须先处理房间；解散已开局房间会生成总结算，玩家停留在结算画面，自行返回大厅。俱乐部有人在房间时不能直接关闭。所有操作均由服务端校验。

游戏运行快照仍仅保留最近 300 场；后台另建牌局归档表，上线时回填快照里现存的最多 300 场，以后每场结算持续保存。已被旧策略删除的更早战绩无法恢复。归档保留结算与每局积分、回放编号，回放原始数据仍遵循游戏运行快照的保留策略。旧玩家没有注册时间，新玩家注册趋势从本功能上线后开始计算。审计日志与牌局归档分开存储，不会随快照重写而丢失；备份生成在 /var/lib/qjqp/backups/。

首次设置或紧急重置管理员密码，可在服务器上执行：

~~~bash
node /opt/qjqp/tools/admin-set-password.js /var/lib/qjqp/admin-password.json < /安全路径/密码文件
chown qjqp:qjqp /var/lib/qjqp/admin-password.json
systemctl restart qjqp
~~~

脚本从标准输入读取密码，命令行和 Git 中不保存密码原文。初始密码至少 12 个字符。管理员密码与此前运营消息的 SSH 密钥相互独立。
